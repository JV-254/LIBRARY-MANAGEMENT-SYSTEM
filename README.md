# LIBRARY-MANAGEMENT-SYSTEM
## Project Overview
This project is meant to help on library management .Keeping records of books borrowed, who borrowed it and what date it was borrowed.
## Tools Used
- SQL Server
## Key Objectives
- Help in keeping record of the books borrowed
- Monitoring the book from the date of borrow to the return date
- Keep record of names of the people who have borrowed the books
## Key Insights
- The project is able to order the books according to the date of borrowing
